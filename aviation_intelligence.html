01The Problem

Airlines don't just have late flights.
They have an operational reliability problem.

A delayed flight can affect aircraft utilization, crew schedules, airport capacity, connecting passengers, and subsequent operations. The project therefore starts with a business question—not a chart.

CENTRAL QUESTION

Why are flights delayed, and can we identify flights at high risk of significant delay before departure?

06SQL Analysis

Business question → query

Use SQL to aggregate carrier and airport performance instead of treating SQL as a standalone skill badge.

SELECT OP_UNIQUE_CARRIER,
       AVG(ARR_DELAY) AS avg_arr_delay
FROM flights
GROUP BY OP_UNIQUE_CARRIER
ORDER BY avg_arr_delay DESC;

07Predictive Phase

The ML stage begins only after the descriptive and diagnostic foundations are trustworthy.

TARGET DEFINITION

Can we predict whether a flight will experience a significant delay before departure?

A candidate classification target is a significant delay threshold such as 15 minutes. The final target must be defined carefully and evaluated for class balance.

LEAKAGE CHECK

Only information available at prediction time belongs in the model.

Future outcome variables such as ARR_DELAY and delay-cause fields should not be used as features for a pre-departure prediction model.

Baselinesimple rule / logistic regression
Modelstree-based + learned models
Evaluateprecision / recall / F1 / ROC-AUC
Operaterisk score → intervention priority
